1. Project Overview

This bonus project extends the ROS 2 SLAM and mapping project by implementing AMCL (Adaptive Monte Carlo Localization) for robot localization using a previously generated and saved map.

The project demonstrates the complete navigation localization pipeline:

Gazebo Simulation
       ↓
      LiDAR
       ↓
     /scan
       ↓
   Saved Map
       ↓
Localization/AMCL
       ↓
     RViz2

The robot first uses SLAM Toolbox to create a map of the environment. The resulting map is then saved and reused for localization.

Instead of continuously creating a new map, AMCL estimates the robot's pose within the existing map using LiDAR observations and odometry.

7. AMCL Localization

AMCL stands for:

Adaptive Monte Carlo Localization
AMCL estimates the robot's position and orientation inside a known map.

Unlike SLAM, AMCL does not create a new map.
Instead use the previously saved mapped map

AMCL uses a particle filter to represent possible robot poses, which adapt probability theories (Bayes theorem and gaussian theorem)
Each particle represents a possible hypothesis for the robot's location.

When the robot receives sensor observations, AMCL compares the expected observations with the actual LiDAR measurements and updates the particle weights.
Particles that better match the environment receive higher probability.

Over time, the particle distribution converges around the robot's actual pose.

9. Testing Localization Robustness
Several tests performed.

Test 1 — Correct initial pose
1. Start Gazebo.
2. Load the saved map.
3. Start AMCL.
4. Start RViz2.
5. Set the approximate robot pose.
6. Observe the particle cloud.
7. Verify convergence.

Test 2 — Incorrect initial pose
1. Start AMCL.
2. Give RViz2 an intentionally incorrect pose.
3. Observe the particle distribution.
4. Move the robot.
5. Observe whether AMCL converges toward the correct location.

Test 3 — Different robot locations
Move the robot to several locations in the environment and verify that the estimated AMCL pose follows the robot.

Test 4 — Different orientations
Place the robot facing different directions and verify that AMCL estimates the correct orientation.

10. Final Result
The completed project demonstrates a complete simulated robot localization pipeline.
The robot is first used to generate a map using SLAM Toolbox. The map is saved and then supplied to the localization system.
To estimate the robot's pose. RViz2 provides visual confirmation of the localization process through the map, robot model, LaserScan, TF frames, and AMCL particle cloud.
The successful convergence of the particles demonstrates that the robot can localize itself within a previously known environment.
